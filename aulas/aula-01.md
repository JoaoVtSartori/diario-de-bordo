## Aula 01 - O que aprendi
Na primeira aula, aprendi a diferença entre Git e GitHub. O Git é uma ferramenta que registra as versões e as alterações de um projeto, enquanto o GitHub é uma plataforma online que permite armazenar repositórios e
colaborar com outras pessoas. Também aprendi que os commits registram as mudanças realizadas e que o histórico permite consultar as versões anteriores de um projeto.
